## Как пользоваться

1. Скачай любой клиент из таблицы ниже.
2. Добавь подписку по ссылке выше.
3. Обнови список серверов.
4. Выбери рабочий и подключайся.

Не заходи в российские сервисы (ВК, Яндекс, Госуслуги и т.д.) с включённым VPN. Сначала выключи VPN, зайди в сервис, потом снова включи. Иначе конфиг могут заблокировать.

## Важные моменты

- Конфиги взяты из открытых и слитых источников. Я не владею серверами.
- Работа зависит от оператора, региона и конкретного сервера. У кого-то будет работать лучше, у кого-то хуже.
- Безопасность не гарантируется. Используй на свой страх и риск.
- Если подписка перестала работать — просто обнови её. Она обновляется каждый день.
- Проект небольшой. Цель — просто давать рабочие ссылки, чтобы люди могли выходить в интернет.
